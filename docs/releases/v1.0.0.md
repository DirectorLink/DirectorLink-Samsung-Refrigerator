# Samsung Refrigerator (DirectorLink) v1.0.0

**A free, open-source Control4 driver for Samsung Wi-Fi refrigerators, by DirectorLink.**

The first release. It controls and monitors Samsung refrigerators through the Samsung SmartThings cloud,
with no extra hardware and no subscription.

## In the Control4 app

- **Samsung Refrigerator** tile: green when all is well, amber with the door drawn open when a door is open, red when the refrigerator is offline or needs authorization. Tap it to refresh.
- **Power Cool**, **Power Freeze**, **Sabbath Mode** and **Ice Maker** tiles: tap to switch on or off. A tile shows a feature as changed only when the refrigerator confirms it, typically in about 4 seconds. Features your model doesn't have are greyed out.
- Keypad buttons can be bound to each feature tile; their LEDs follow the state.

## In Composer

- **Programming:**
  - Commands: *Set Feature* (On / Off / Toggle), fridge and freezer setpoints, reset the water filter, refresh.
  - Events: each feature turning on or off, Setpoint Changed, Door Opened / Closed / **Left Open**, Water Filter Needs Replacement, Refrigerator Offline / Online, Command Failed, Authorization Required.
  - Conditionals and variables for every feature, the doors, the temperatures and power.
- **Status:** fridge and freezer temperatures and setpoints (pick a new setpoint from the dropdown), doors, FlexZone mode, water filter, power and energy, model, and which features this refrigerator supports.

## Setup in short

1. Create a SmartThings Personal Access Token with **all Devices, Locations and Apps** scopes ticked, and paste it into the driver.
2. Click **1. Create OAuth App**: the driver creates its own Client ID and Secret.
3. Click **2. Show Authorization URL**, sign in once in a browser, and paste the address you land on into **Authorization Code**. If it goes into the wrong field, the driver notices and signs in anyway.

From then on the driver renews its own access. The 24-hour token isn't needed again. The full steps are in the README and on the driver's Documentation tab.

## Good to know

- Commands go through Samsung's cloud. Doors and temperatures are read every 2 minutes by default, so door events can come up to that late.
- Which features appear depends on the model and its firmware, as SmartThings reports them. For example, some Family Hub units have Sabbath mode disabled in SmartThings.
- Tokens are kept in Control4's encrypted driver storage and are never written to the log.

## Tested on

- Live: RF85T901335ML (SmartThings `TP2X_REF_20K`) on a CORE-1 with Control4 OS 4.2.1. Tested: Power Cool, Power Freeze, Sabbath mode, both setpoints, sign-in and automatic token renewal.
- Offline: TP2X, TP1X, Family Hub, one-door and older dongle-based models, under Lua 5.1 and LuaJIT.

## Installing

Requires Control4 OS 3.3 or newer. Download `DirectorLink-Samsung-Refrigerator.c4z`, and check it against `SHA256SUMS.txt` if you like. Add it in Composer Pro with **Driver → Add or Update Driver**, then add **Samsung Refrigerator (DirectorLink)** to the kitchen.

Keep the file name exactly `DirectorLink-Samsung-Refrigerator.c4z`. A browser saves a second download as `... (1).c4z`, which Composer installs as a separate driver, so delete older downloads first.
