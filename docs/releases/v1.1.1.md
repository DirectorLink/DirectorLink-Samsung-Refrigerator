# DirectorLink · Samsung Refrigerator 1.1.1

DirectorLink is an independent project, not affiliated with Control4 or Snap One.

## What changes

- The README and the driver's Documentation tab in Composer now say so near the top.
- Every link people see was checked. DirectorLink's source is at https://github.directorlink.io, and this driver's
  page, with downloads, updates and help, is https://directorlink.io/drivers/samsung-refrigerator.

Nothing else changes. The driver works exactly as in 1.1.0: the tiles, properties, commands, events,
conditionals and all fourteen variables are the same, and programming keeps working.

## Updating

In Composer Pro: **Driver → Add or Update Driver or Agent**, then select `DirectorLink-Samsung-Refrigerator.c4z`.
No reboot or re-adding is needed, and the SmartThings sign-in is kept. Keep the file name exactly as it is:
a browser's `... (1).c4z` copy installs as a separate driver.
