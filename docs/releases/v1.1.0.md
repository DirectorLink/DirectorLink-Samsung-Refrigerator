# DirectorLink · Samsung Refrigerator 1.1.0

Works with DirectorLink 1.7 and later: the app shows only the switches and values this refrigerator has, in the right unit.

## What's new

Two new variables, added after the existing twelve. Those keep their ids (1001–1012), so programming keeps working.

- **REPORTED_VARIABLES** (id 1013): which of the twelve variables hold a value this refrigerator reports, comma-separated.
  A feature shown as *Not available*, a missing door sensor or water filter, or a zone without a temperature or
  setpoint isn't listed. Its variable stays at `0`, which would otherwise read as off, closed or 0°.
  It updates after each status read when the list changes, and is empty before the first read, after
  **Sign Out**, and when another refrigerator is selected.
- **TEMPERATURE_UNIT** (id 1014): `C` or `F`, the unit the refrigerator uses for its temperatures and setpoints.
  Empty while unknown.

Nothing else changes: the tiles, properties, commands, events, conditionals and the twelve existing
variables work as before.

## Updating

In Composer Pro: **Driver → Add or Update Driver or Agent**, then select `DirectorLink-Samsung-Refrigerator.c4z`.
No reboot or re-adding is needed, and the SmartThings sign-in is kept. Keep the file name exactly as it is:
a browser's `... (1).c4z` copy installs as a separate driver.
