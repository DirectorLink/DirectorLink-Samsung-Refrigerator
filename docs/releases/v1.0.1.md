# DirectorLink · Samsung Refrigerator 1.0.1

The driver joins **DirectorLink Drivers**, a family of free, open-source Control4 drivers.
This release changes names and text only. The driver works exactly as in 1.0.0.

## What changes

- **New name in Composer:** **DirectorLink · Samsung Refrigerator** (it was *Samsung Refrigerator (DirectorLink)*).
  Search Composer for "DirectorLink" to find it. Devices already in your project keep the names they have.
- The model shown in Composer is now *Refrigerator (SmartThings)*.
- The driver now identifies itself to SmartThings as `DirectorLink-Samsung-Refrigerator/1.0.1`.
- New home for downloads, updates and help: https://directorlink.io/drivers/samsung-refrigerator
- The Documentation tab, README and notices follow the DirectorLink Drivers style.
- With DirectorLink 1.7.0 or later, the refrigerator also shows in the DirectorLink app.

## What stays the same

The file name `DirectorLink-Samsung-Refrigerator.c4z`, the tiles and their names, properties, commands,
events, conditionals and variables are unchanged. Programming keeps working. The SmartThings sign-in is kept.

## Updating

In Composer Pro: **Driver → Add or Update Driver or Agent**, then select `DirectorLink-Samsung-Refrigerator.c4z`.
No reboot or re-adding is needed. Keep the file name exactly as it is: a browser's `... (1).c4z` copy installs
as a separate driver.
