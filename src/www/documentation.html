Samsung Refrigerator (DirectorLink)

A free, open-source driver by DirectorLink: directorlink.io. Updates, help and bug reports: github.com/IsraelCIL/DirectorLink-Samsung-Refrigerator

Control and monitor Samsung Wi-Fi refrigerators from Control4 through the Samsung SmartThings cloud. The driver checks which features your model supports. Anything the model doesn't support shows as Not available.

Requirements

  • The refrigerator is on Wi-Fi and added to the homeowner's SmartThings app.
  • The controller has internet access (HTTPS to api.smartthings.com).
  • About 10 minutes, a browser, and the login of the Samsung account the refrigerator is registered to.

Setup

Step 1 - Create a SmartThings Personal Access Token

  1. On a computer, open https://account.smartthings.com/tokens.
  2. Sign in with the same Samsung account that the refrigerator is registered to in the SmartThings app.
  3. Click Generate new token and give it any name, for example Control4.
  4. Under Authorized Scopes, tick every checkbox in these three sections: Devices, Locations, Apps. If in doubt, tick everything on the page. The token is used once and expires after 24 hours.
  5. Click Generate token and copy the value, which looks like 1a2b3c4d-1111-2222-3333-444455556666. It's shown only once.
  6. In Composer, paste it into the Personal Access Token property and click Set.
Common token mistakesWhat you see
No checkboxes tickedCreate app failed: Forbidden
Only Devices ticked (Apps missing)Create app failed: Forbidden ... needs ALL Apps scopes
Token older than 24 hoursCreate app failed: Not authorized. Create a new token.
Signed in with a different Samsung accountNo refrigerators found

Step 2 - Create the OAuth app (this creates your Client ID)

On the Actions tab click 1. Create OAuth App (uses Personal Access Token). OAuth Client ID and OAuth Client Secret fill in by themselves, and Authorization Status says OAuth app created.

There is nothing to look up: the driver creates the Client ID for you. SmartThings never shows the secret again, so write both values down. If you add the driver again later, paste the same Client ID and Secret instead of creating a new app.

Step 3 - Authorize (sign in once)

  1. Click 2. Show Authorization URL. The link appears on the Lua tab (Lua Output) and in the Authorization URL property.
  2. Open it in a browser and sign in with the same Samsung account. Choose the location with the refrigerator, then click Authorize.
  3. The browser goes to a page whose address starts with https://httpbin.org/get?code=. Copy the whole address from the address bar.
  4. Within a few minutes, paste it into the Authorization Code property and click Set. Codes expire; if it fails, open the link again. Pasted it into OAuth Redirect URI or Personal Access Token by mistake? The driver notices, puts that field back, and signs in anyway.

Authorization Status now reads Authorized (OAuth) ... renews automatically. From now on, the driver renews its access itself. The Personal Access Token isn't needed anymore.

Step 4 - Select the refrigerator

Discovery runs after authorization. With one refrigerator it is selected for you; otherwise choose it in Select Refrigerator. Check Supported Features to see what your model offers.

Step 5 - Show the tiles in the Control4 app

The driver appears in the room as Samsung Refrigerator. It adds five UI buttons: the Samsung Refrigerator status tile and the feature tiles Power Cool, Power Freeze, Sabbath Mode and Ice Maker. In Composer, open the room's Navigator settings and make the ones you want visible on a menu (for example Comfort). Hide the ones your model doesn't support. Each feature tile can also be bound to a keypad button (connections Keypad Button: ...); the button LED follows the state.

Tile icons

Samsung Refrigerator (status): green ring = OK; amber ring with the door drawn open = a door is open; white ring = refreshing (tap the tile to refresh); red ring = offline, authorization needed or the last refresh failed; gray = not set up yet.

Examples

  • Shabbat: Scheduler event Friday at sunset minus 30 minutes runs Set Feature Sabbath Mode On. Saturday at sunset plus 60 minutes runs Sabbath Mode Off. Add a push notification on Command Failed.
  • Groceries: a keypad button runs Power Cool On. The refrigerator turns it off by itself when done.
  • Door alarm: on Door Left Open, send a notification or flash a light.

Commands go through the Samsung cloud, so they need internet. Doors and temperatures are polled (default every 2 minutes), so door events can be delayed by up to the poll interval. Changes made on the refrigerator itself also show up in Control4.

Troubleshooting

  • Create app failed: see the token mistakes table in Step 1.
  • Authorization failed: the code expired or was already used. Open the link again and paste the new address quickly.
  • Re-authorization required: SmartThings rejected the saved token, for example after about 30 days with the controller offline, or after access was removed in the SmartThings app. Repeat Step 3. Steps 1-2 aren't needed.
  • A feature shows Not available: your model or its firmware doesn't expose it to SmartThings. Check for a refrigerator update in the SmartThings app.
  • ... was not confirmed by the refrigerator: SmartThings accepted the command but the refrigerator didn't change. Check that it is online in the SmartThings app.
  • Rate limited: SmartThings allows about 12 reads per minute per device. Avoid very short poll intervals, and don't fire many commands at once.

Privacy and security

The driver talks only to api.smartthings.com. Tokens are kept in Control4's encrypted storage. The Client Secret is a masked property, but anyone with Composer access to the project can read it. To revoke access, remove DirectorLink Samsung Refrigerator from the connected services in the SmartThings app, or click Sign Out (clear tokens).

Updates

Download new versions from the GitHub page above (Releases) and install them with Driver → Add or Update Driver. The file must be named exactly DirectorLink-Samsung-Refrigerator.c4z. A copy named DirectorLink-Samsung-Refrigerator (1).c4z would be added as a separate driver instead of updating this one, so delete older downloads first.
